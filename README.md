# TechNova Sentiment Analysis

## About the Project
This project focuses on Sentiment Analysis using Python and Natural Language Processing (NLP). It analyzes text data and identifies the sentiment expressed in the text, such as positive or negative.

Developed as part of the **TechNova AI Internship**, this project demonstrates text preprocessing, sentiment classification, and basic machine learning concepts.

## Objectives
- Analyze text data to identify sentiment.
- Apply Natural Language Processing techniques.
- Classify text into sentiment categories.
- Understand how machine learning can be used for text classification.
